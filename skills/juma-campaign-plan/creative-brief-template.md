# Per-Channel Creative Brief Template

Use this template to create a mini-brief for each channel selected in the campaign plan. Each channel needs its own brief to ensure messaging is adapted to the platform's format, audience behavior, and specs.

---

## Creative Brief: [Channel/Platform Name]

```
Channel: [Platform/Channel]
Objective: [Channel-specific goal, e.g., "Drive 500 demo requests at $45 CPL"]
Audience: [Platform-specific targeting -- demographics, interests, custom audiences, lookalikes]
Message: [Adapted key message for this channel's context and audience mindset]
Format: [Ad format or content type -- e.g., single image ad, carousel, 15s video, blog post]
CTA: [Channel-appropriate action -- e.g., "Book a Demo", "Download the Guide", "Shop Now"]
Landing page: [Destination URL -- dedicated landing page or website page]
Assets needed: [Specific deliverables -- copy variations, images, video, etc.]
Specs: [Platform dimensions, character limits, file formats, max file size]
```

---

## Channel-Specific Considerations

### Paid Social (Meta, LinkedIn, TikTok)
- **Format options:** Single image, carousel, video (6s/15s/30s), lead gen form, stories/reels
- **Copy limits:** Vary by platform -- Meta primary text (125 chars above fold), LinkedIn intro (150 chars above fold)
- **Creative guidance:** Platform-native content outperforms polished ads; adapt tone to platform culture
- **Targeting notes:** Document audience definition, exclusions, and lookalike/custom audience sources

### Paid Search (Google, Bing)
- **Format options:** Responsive search ads, display ads, Performance Max, video (YouTube)
- **Copy limits:** Headlines (30 chars x 15), Descriptions (90 chars x 4)
- **Creative guidance:** Keyword-aligned headlines, strong CTAs, leverage all available extensions
- **Targeting notes:** Keyword list, match types, negative keywords, audience layering

### Email Marketing
- **Format options:** Single send, drip sequence, newsletter placement
- **Copy elements:** Subject line (40-60 chars), preview text, body copy, CTA button
- **Creative guidance:** Personalization tokens, mobile-first design, single clear CTA
- **Targeting notes:** List segment, automation triggers, send timing

### Content Marketing
- **Format options:** Blog post, guide, infographic, video, podcast, webinar
- **Copy elements:** Headline, meta description, body content, internal CTAs
- **Creative guidance:** SEO-optimized, audience-appropriate depth, clear next steps
- **Targeting notes:** Target keywords, distribution channels, promotion plan

### Organic Social
- **Format options:** Feed post (image/video/carousel), stories, reels, threads
- **Copy limits:** Vary by platform -- Instagram (2,200 chars), LinkedIn (3,000 chars), X/Twitter (280 chars)
- **Creative guidance:** Native to each platform, engagement-focused, community voice
- **Targeting notes:** Hashtags, tagging strategy, posting schedule

## Brief Checklist

Before finalizing each channel brief, confirm:

- [ ] Objective is specific and measurable
- [ ] Message is adapted for the channel (not copy-pasted from the master message)
- [ ] All required asset specs are documented
- [ ] Landing page destination is confirmed and optimized for this traffic
- [ ] CTA matches the funnel stage and channel context
- [ ] Targeting is defined with enough detail for execution
