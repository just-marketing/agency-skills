# Prioritized Action Plan Template

Use this template to organize all SEO audit findings into a time-bound, prioritized action plan. Every recommendation is categorized by severity, effort, estimated impact, and ownership.

---

## Priority Levels

| Priority | Timeframe | Criteria |
|----------|-----------|----------|
| **Critical** | Fix within 2 weeks | Issues causing immediate traffic/revenue loss or blocking indexation |
| **High** | Fix within 30 days | Significant impact on rankings or traffic; high ROI fixes |
| **Medium** | Fix within 60 days | Moderate impact; contributes to overall SEO improvement |
| **Low** | Fix within 90 days | Minor improvements; polish and optimization |

## Effort Estimation Guide

| Effort Level | Description | Typical Examples |
|-------------|-------------|-----------------|
| **Quick Fix** | 1-4 hours, single person | Fix a robots.txt rule, add missing title tags, submit sitemap |
| **Moderate** | 1-5 days, single person | Optimize page speed, restructure internal linking, write meta descriptions |
| **Major Project** | 1-2 weeks, may need multiple people | Content overhaul, site migration cleanup, comprehensive schema implementation |
| **Strategic Initiative** | 2+ weeks, cross-functional | Full content cluster strategy, link building campaign, site architecture redesign |

## Impact Estimation Guide

| Impact Level | Description | Quantification |
|-------------|-------------|----------------|
| **High** | Directly affects rankings for high-volume keywords or fixes a conversion blocker | Estimated 20%+ traffic improvement to affected pages |
| **Medium** | Improves rankings for moderate-volume keywords or removes significant friction | Estimated 5-20% traffic improvement to affected pages |
| **Low** | Incremental improvement, minor ranking or UX benefit | Estimated <5% traffic improvement to affected pages |

## How to Prioritize

Order recommendations by **impact-to-effort ratio**:
1. High impact, quick fix = top of the list
2. High impact, moderate effort = next
3. Medium impact, quick fix = next
4. High impact, major project = plan and schedule
5. Low impact items = backlog unless quick fixes
